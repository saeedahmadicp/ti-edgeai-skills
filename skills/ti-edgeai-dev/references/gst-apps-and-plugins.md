# edgeai-gst-apps: config schema, pipeline anatomy, plugins

Source of truth on the board: `/opt/edgeai-gst-apps/configs/app_config_template.yaml` (every option, with comments),
`configs/gst_plugins_map.yaml` (SoC -> plugin names), `apps_python/{config_parser,gst_wrapper,infer_pipe,post_process}.py`.
The generator/validator in `ti-edgeai-generate-config` encode this schema.

## Config sections
```yaml
title: "..."
inputs:   {input0: {source, format, width, height, framerate, [loop], [index], [subdev-id], [drop], [pattern]}}
models:   {model0: {model_path, [viz_threshold | topN | alpha], [labels_path]}}
outputs:  {output0: {sink, width, height, [overlay-perf-type], [connector], [bitrate], [host], [port], [encoding], [gop-size]}}
flows:    {flow0: [input0, model0, output0]}              # or [.., [x, y, w, h]] mosaic rectangle in the output
```
- Input `source`: `/dev/videoN` camera; `dir/%04d.jpg|png` image sequence; `*.h264|h265` raw video; `*.mp4|mov`;
  `rtsp://...`; `http://...`; `videotestsrc`. `format`: `jpeg|yuv|raw|auto` for cameras (CSI raw: `rggb`),
  `h264|h265|auto` for video. Defaults: framerate 30 (camera) / 1 (images).
- Output `sink`: `kmssink` (display), `*.jpg|png` with `%04d` (images), `*.mkv|mp4|mov` (video), `remote` (stream:
  `port` default 8081, `encoding` jpeg|h264|mp4), `fakesink`.
- App-enforced rules: output size <= input size; mosaic must fit inside the output; several flows sharing an output
  need mosaics.
- `loop: True` repeats a file input; `drop: True` (default for cameras) drops frames at the appsink when inference lags.

## Pipeline anatomy (generated by the app; dumped on a TDA4VM)
With the SoC key exported (`SOC=j721e` on TDA4VM):
```
v4l2src/filesrc ... ! [decoder v4l2h264dec] ! tiovxdlcolorconvert ! (NV12) tiovxmultiscaler name=split_01
split_01. ! queue ! tiovxdlcolorconvert ! (RGB) ! appsink name=sen_0                      # full-res branch for overlay/output
split_01. ! queue ! (video/x-raw,width=W,height=H) ! tiovxdlpreproc ... ! application/x-tensor-tiovx ! appsink name=pre_0
                                                                                            # model branch -> inference
post-processed frames -> appsrc ! ... ! tiovxmosaic/overlay ! (kmssink | jpegenc | v4l2h264enc ! matroskamux | ...)
```
- Inference is **not** a GStreamer element in the Python app: the app pulls tensors from `pre_0`, runs ONNX Runtime/TIDL,
  draws, and pushes frames to `appsrc`. The GStreamer tracers therefore do not include inference time; measure that with
  `ti-edgeai-profile-pipeline/scripts/bench_tidl.py`. OpTIFlow and the C++ app (`apps_cpp/`) are the variants that put more
  of this inside GStreamer (not exercised here).
- Without `SOC` the same config yields `videoscale ! videoconvert ! appsink` (CPU path).
- `tiovxdlpreproc` properties include `data-type`, `tensor-format` (RGB/BGR), `channel-order` (NCHW/NHWC),
  `mean-0..2`, `out-pool-size`. The app derives them from `param.yaml`: `reverse_channels: true` produced
  `tensor-format=1` (BGR) and the uint8 `data-type` in the pipeline dump.
- tiovxmultiscaler does not support odd resolutions.

## SoC map from gst_plugins_map.yaml (j721e column verified on TDA4VM)
j721e, j721s2, j784s4, j722s and am62a all map to the same `tiovx*` elements below (checked in TI's file; only j721e was run).
am62x/am62p use `tiscaler`/`tidlpreproc`/`timosaic`, and `arm` is the CPU-only fallback.
| role | element |
|---|---|
| dlcolorconvert / colorconvert | `tiovxdlcolorconvert` / `tiovxcolorconvert` (target [0,1]) |
| scaler | `tiovxmultiscaler` (target [0,1]) |
| dlpreproc | `tiovxdlpreproc` |
| mosaic / isp / ldc | `tiovxmosaic` / `tiovxisp` / `tiovxldc` |
| h264 / h265 decode | `v4l2h264dec` (capture-io-mode 5) / `v4l2h265dec` |
| h264 encode | `v4l2h264enc` (h265 encode: none) |
| inferer | target `dsp`, core-id `[1]` |

## Model folder contract (what the app reads)
`param.yaml` keys used by the app: `task_type: detection|classification|segmentation`, `preprocess.{resize,crop,
reverse_channels,resize_with_pad,data_layout}`, `postprocess.{formatter,resize_with_pad,normalized_detections,...}`,
`session.{model_path,artifacts_folder,input_details,output_details,session_name,target_device}`,
`metric.label_offset_pred` (class index -> category id), plus `dataset.yaml` categories for label text.
`ti-edgeai-import-model/scripts/package_model.py` writes these.
